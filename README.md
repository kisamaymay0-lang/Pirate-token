# PirateChestToken

Плагин для Paper/Purpur 1.21.1+ (Java 21). При успешном броске шанса исходный сундук скрывается для зрителей, а вместо него появляется сущность ванильной вагонетки с сундуком (`CHEST_MINECART`): Minecraft сам рисует на ней стандартную модель и текстуру сундука. Сущность трясётся, исчезает с частицами, после чего над местом сундука поднимается светящаяся надпись токена с частицами. Сам токен — только визуальная анимация, предмет токена не создаётся.

После анимации оставшийся инвентарь сундука выбрасывается на землю, а настоящий блок сундука удаляется. При неудачном броске шанса сундук открывается обычным образом.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Paper или совместимое ядро Purpur 1.21.1+

## Сборка и установка

Из корня репозитория выполните:

```bash
mvn clean package
```

Готовый файл: `target/pirate-chest-token-1.0.0.jar`. Скопируйте его в `plugins/` сервера и перезапустите сервер. Paper API имеет scope `provided`, поэтому API сервера не упаковывается внутрь JAR; сторонние библиотеки и shade-плагин не нужны.

## Настройка

При первом запуске плагин создаст `plugins/PirateChestToken/config.yml`:

```yaml
drop-chance: 0.001          # 0.001 = 0.1%; диапазон 0..1
debug: false
title-enabled: true
sound-enabled: true
particle-enabled: true
glow-radius: 30
glow-duration-ticks: 30
shake-duration-ticks: 12
token-animation-ticks: 50
token-name: "🏴‍☠️ Pirate Shop Access"
```

Для гарантированного теста временно выставьте `drop-chance: 1.0`. Шанс `0.01` означает 1%, `0.001` — 0.1%. Настройки применяются после перезапуска сервера.

## Последовательность и ограничение модели

Для двойного сундука шанс проверяется один раз на открытие. При выигрыше `InventoryOpenEvent` отменяется, поэтому исходный сундук не открывает обычный GUI. Плагин временно подменяет блок для зрителей и показывает native chest minecart entity с ванильной текстурой сундука, затем удаляет сущность с частицами, ломает настоящий сундук и выбрасывает оставшиеся предметы. Игрок, вышедший во время тряски, отменяет анимацию; подмена блока восстанавливается, сундук не ломается.

В ванильной Java нет отдельной сущности «сундук-блок»: сам блок отрисовывается как block entity, поэтому `BlockDisplay` с `Material.CHEST` не показывает его модель. Для точной модели и текстуры без вагонетки нужен ресурспак или клиентский мод. Здесь используется ближайший вариант без ресурспака — настоящая сущность вагонетки с сундуком, у которой Minecraft рисует ту же ванильную модель/текстуру сундука (под ней остаётся видна часть вагонетки).
