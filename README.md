# PirateChestToken

Плагин для Paper/Purpur 1.21.1+ (Java 21). При успешном броске шанса сундук сначала заметно покачивается, затем открывается обычным инвентарём. Над ним поднимается светящаяся надпись токена с частицами; после анимации сундук разрушается, а содержимое выпадает на землю. Сам токен — только визуальная анимация, предмет токена в инвентарь и на землю не создаётся.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Paper или совместимое ядро Purpur 1.21.1+

## Сборка и установка

Из корня репозитория выполните:

```bash
mvn clean package
```

Готовый файл: `target/pirate-chest-token-1.0.0.jar`. Скопируйте его в `plugins/` сервера и перезапустите сервер. Paper API имеет scope `provided`, поэтому API сервера не упаковывается внутрь JAR; сторонние библиотеки и shade-плагин не нужны.

## Настройка

При первом запуске плагин создаст `plugins/PirateChestToken/config.yml`:

```yaml
drop-chance: 0.001          # 0.001 = 0.1%; диапазон 0..1
debug: false
title-enabled: true
sound-enabled: true
particle-enabled: true
glow-radius: 30
glow-duration-ticks: 30
shake-duration-ticks: 12
token-animation-ticks: 50
token-name: "🏴‍☠️ Pirate Shop Access"
```

Шанс задаётся дробью: `0.01` — 1%, `0.001` — 0.1%, `1.0` — 100%. Настройки применяются после перезапуска сервера.

## Последовательность анимации

При неудачном броске шанса сундук открывается обычным образом. При выигрыше `InventoryOpenEvent` отменяется, поэтому GUI и крышка не открываются мгновенно. Плагин на короткое время меняет блок-данные только на клиенте, поворачивая направление сундука туда-обратно; это серверный визуальный компромисс для эффекта «дрожания». Затем плагин открывает исходный инвентарь программно и не проверяет шанс повторно. Это работает и для двойного сундука: одно событие — один бросок.

Во время анимации над сундуком появляется ванильный `TextDisplay` с именем из `token-name`; он плавно поднимается, светится и сопровождается частицами. Это текстовая сущность, не `ItemStack`. Когда анимация заканчивается, плагин закрывает GUI у игроков, у которых открыт этот инвентарь, выбрасывает оставшиеся предметы инвентаря на землю и убирает сундук. Если открывший игрок выходит или вручную закрывает инвентарь во время последовательности, анимация отменяется, сундук не ломается и временная подмена блока восстанавливается.

Частота вращения блока ограничена ванильными состояниями, поэтому это не физическая деформация модели. Без ресурспака сервер не может создать пользовательскую модель токена или заставить блок-сундук получить точный glowing-контур. Надпись и частицы — ближайшая ванильная имитация: для собственного изображения токена или точной модели нужен ресурспак/клиентский мод. Невидимая marker-стойка используется только как световой контур для окружающих игроков, не как сам токен.
