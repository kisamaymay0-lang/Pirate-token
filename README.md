# PirateChestToken

Плагин для Paper/Purpur 1.21.1+ (Java 21). При успешном броске шанса сундук на время превращается для зрителей в трясущуюся сущность из ванильных `BlockDisplay`: деревянный корпус, крышка и золотой замок. Она исчезает с облаком и частицами; затем над местом сундука поднимается светящаяся надпись токена с частицами. Сам токен — только визуальная анимация, предмет токена не создаётся.

После анимации оставшийся инвентарь сундука выбрасывается на землю, а сам блок сундука удаляется. При неудачном броске шанса сундук открывается обычным образом.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Paper или совместимое ядро Purpur 1.21.1+

## Сборка и установка

Из корня репозитория выполните:

```bash
mvn clean package
```

Готовый файл: `target/pirate-chest-token-1.0.0.jar`. Скопируйте его в `plugins/` сервера и перезапустите сервер. Paper API имеет scope `provided`, поэтому API сервера не упаковывается внутрь JAR; сторонние библиотеки и shade-плагин не нужны.

## Настройка

При первом запуске плагин создаст `plugins/PirateChestToken/config.yml`:

```yaml
drop-chance: 0.001          # 0.001 = 0.1%; диапазон 0..1
debug: false
title-enabled: true
sound-enabled: true
particle-enabled: true
glow-radius: 30
glow-duration-ticks: 30
shake-duration-ticks: 12
token-animation-ticks: 50
token-name: "🏴‍☠️ Pirate Shop Access"
```

Для гарантированного теста временно выставьте `drop-chance: 1.0`. Шанс `0.01` означает 1%, `0.001` — 0.1%. Настройки применяются после перезапуска сервера.

## Последовательность

Для двойного сундука шанс проверяется один раз на открытие. При выигрыше `InventoryOpenEvent` отменяется, поэтому исходный сундук не открывает обычный GUI. Плагин скрывает блок клиентской подменой, показывает вместо него движущиеся vanilla display entities, затем с частицами удаляет их и ломает настоящий сундук. Оставшиеся предметы инвентаря выбрасываются на землю. Игрок, вышедший во время тряски, отменяет анимацию; временная подмена блока восстанавливается, сундук не ломается.

Сундук — специальный block entity, а не обычная модель блока, поэтому один `BlockDisplay` с данными `Material.CHEST` не даёт надёжной анимированной модели сундука. Для эффекта используются ванильные display-сущности из дубовых деталей и золотого замка — узнаваемая, но упрощённая имитация. Точный внешний вид и текстуры требуют ресурспака/клиентского мода. Надпись токена сделана ванильным `TextDisplay`; она не является предметом и не требует ресурспака.
