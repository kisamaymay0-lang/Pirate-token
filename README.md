# PirateChestToken

Плагин для Paper/Purpur 1.21.1+ (Java 21). При открытии сундука с заданным
шансом игрок находит **токен Пиратского Магазина**:

1. Сундук коротко трясётся (для зрителей рядом), звучит скрип крышки.
2. Затем сундук открывается по-настоящему — ванильной анимацией крышки.
3. Над сундуком взлетает светящаяся надпись токена с частицами и свечением,
   игроку показывается тайтл и звук находки.
4. Игрок получает **настоящий предмет-токен** в инвентарь.

Сундук и его содержимое остаются целыми. По желанию старое поведение
(сундук разрушается, содержимое падает на землю) включается в конфиге.

## Требования

- Java 21 (JDK)
- Maven 3.8+
- Paper или совместимое ядро Purpur 1.21.1+

## Сборка и установка

```bash
mvn clean package
```

Готовый файл: `target/pirate-chest-token-1.1.0.jar` (также публикуется в
[release «PirateChestToken test build»](../../releases)). Скопируйте JAR в
`plugins/` сервера и перезапустите сервер.

## Команды

| Команда | Описание | Право |
| --- | --- | --- |
| `/piratechesttoken reload` (алиасы `/pctoken`, `/pct`) | Перезагрузить конфигурацию без перезапуска | `piratechesttoken.admin` |

## Права

| Право | Описание | По умолчанию |
| --- | --- | --- |
| `piratechesttoken.drop` | Игрок может найти токен в сундуке | всем |
| `piratechesttoken.admin` | Перезагрузка конфигурации | операторам |

## Настройка

При первом запуске плагин создаст `plugins/PirateChestToken/config.yml`:

```yaml
drop-chance: 0.001          # 0.001 = 0.1%; диапазон 0..1
enabled-worlds: ['*']       # миры, где работает ивент

shake-duration-ticks: 12    # тряска сундука до открытия
token-animation-ticks: 50   # полёт токена над сундуком
glow-radius: 30             # радиус обзора эффектов для зрителей
glow-duration-ticks: 30     # длительность свечения

title-enabled: true
sound-enabled: true
particle-enabled: true

reward:                     # предмет-награда за находку
  enabled: true
  material: GOLD_NUGGET
  name: '&6&l🏴‍☠️ Токен Пиратского Магазина'
  lore:
    - '&7Редкая находка из пиратского сундука.'
    - '&7Храните его как трофей.'
  glow: true

destroy-chest-on-find: false  # true — старое поведение: сундук ломается

token-name: '&6&l🏴‍☠️ Токен Пиратского Магазина'
messages:
  subtitle: '&eТокен Пиратского Магазина найден!'
  actionbar: '&eВы нашли токен Пиратского Магазина!'

debug: false
```

Для гарантированного теста временно выставьте `drop-chance: 1.0` и выполните
`/piratechesttoken reload`. В сообщениях и названиях работают `&`-коды цвета.

## Как это устроено

- Шанс проверяется один раз на открытие сундука (для двойного сундука — один
  раз на весь двойной сундук).
- Награда выдаётся сразу в момент находки и остаётся у игрока, даже если он
  выйдет во время анимации.
- Тряска выполняется клиентской подменой направления блока — поэтому для
  одиночного сундука. Двойной сундук при находке сопровождается только
  частицами и звуком: его половины при повороте визуально рассыпаются.
- Надпись токена — временная сущность `TextDisplay`, свечение для зрителей —
  невидимая marker-стойка. Все сущности убираются по завершении анимации и
  при выключении плагина.
- Если игрок закрывает сундук или выходит во время анимации, анимация
  отменяется, сундук остаётся на месте.
